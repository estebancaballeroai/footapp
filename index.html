Fuente de los datos

ESPN — marcadores, clasificación y detalles, acceso público no oficial. Puede cambiar o bloquear consultas sin previo aviso.

Wikimedia Commons / Wikidata — imágenes bajo demanda, solo con licencias permitidas y atribución individual; si no existe una licencia verificable, no se muestra la imagen.

TheSportsDB — fichas y hasta 10 jugadores por equipo con clave pública gratuita. Wikipedia — historia y enlaces, no transferencias en tiempo real.

GitHub Actions — prepara una caché comunitaria de tablas, fixture y directorios de equipos cada 6 horas (puede retrasarse). El directo sigue utilizando ESPN por dispositivo.

OpenLigaDB — respaldo gratuito y comunitario para Bundesliga y 2. Bundesliga. Los resultados pueden publicarse con retraso.

Sin costes ni claves privadas — no utilizamos una API de pago ni un servidor obligatorio para esta versión.
